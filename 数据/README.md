## 清洗步骤（两套数据同一流程）

0. **εr 数据集以 `/internfs/Zy/dataset/P1070/initial_data`（1,075 行，含 monomer_ID / smiles / dielectric_const_dc / Tg）为准**。它比服务器上的 `DC.csv`（1,073）多 2 条**氘代聚合物**（`[2H]`），现已补回；1,073 条共有记录的数值与该文件完全一致
1. RDKit 解析并输出规范化 SMILES（统一列名 `psmiles`）；解析失败剔除 —— 0 条
2. 只保留**恰好两个 `*`** 的线性重复单元 —— Tg 剔除 82 条（59 条 3 个 `*`、22 条 4 个、1 条 6 个，为支链/交联/网络结构）；eps_r 剔除 0 条
3. 规范化后同一结构多条标签：极差 ≤ 30 ℃ 取中位数合并（Tg 20 组）；**极差 > 30 ℃ 整组剔除**（Tg 5 组，至少一条标签录错、中位数不可信）；eps_r 无重复
4. 标签保留 4 位小数
5. **补充数据**（`D:\Users\YuZen\Desktop\New Microsoft Excel 工作表.xlsx`，382 行，聚磷腈为主，原单位 K）：
   - 保留 K 值在 100–850 K（−173 ~ 577 ℃）的 161 行，换算为 ℃ 后并入
   - 剔除 220 行原值 > 850 K（870 ~ 19,797）的记录——任何单位下都不可能是 Tg
   - 剔除 1 行 RDKit 无法解析
   - 161 行与原有数据无交集

## 需要知道的

- 被剔除的 5 组冲突结构列在 `Tg_duplicates_report.csv`（`action` 列）。其余合并组极差 ≤ 27.5 ℃，在实验 Tg 的常见离散范围内。
- 763 个结构同时出现在两套数据里。
- 补充的 161 条是聚磷腈（`*N=P(...)`）为主的体系，和原有 Tg 数据（聚丙烯酸酯/聚酰亚胺等）化学空间差异较大；若用于训练需注意分布偏移。
- 这里的清洗不是作者的训练口径；要复现论文模型指标请用 `data/ga_mmpolymer/` 原始文件。
